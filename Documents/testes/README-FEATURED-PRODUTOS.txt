FORJ3D - Produtos em destaque

Agora os produtos da Home são controlados pelo campo:

    featured: true

em JS/products-data.js.

Para exibir um produto no carrossel da Home:
    featured: true

Para mantê-lo apenas no catálogo:
    featured: false

Não é necessário editar o index.html para trocar os destaques.
A Home e o catálogo continuam compartilhando a mesma base de produtos.
